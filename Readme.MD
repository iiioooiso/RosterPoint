# Assignment 3: Roster Point

## Overview
**Roster Point** is an innovative platform designed to eliminate the friction of scheduling and workforce management. 

*Roster* (from the Latin *rostrum*) traditionally signifies an official list of personnel. 
*Point* serves as the singular locus of truth—a unified destination where every task and schedule converges without hassle. 

Together, **Roster Point** provides a sleek, centralized hub where you can instantly discover, manage, and execute all your necessary tasks.
